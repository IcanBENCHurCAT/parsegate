# Contributing to IPFS "Pay-to-Pin" Gateway

First off, thank you for considering contributing to the IPFS "Pay-to-Pin" Gateway! It's people like you that make open source such a great community.

## 🤝 For Human Contributors

We welcome contributions of all kinds! Here's how you can help:

### Development Workflow

1. **Fork the repo** and create your branch from `main`.
2. **Install dependencies** using exactly `pnpm install` (Never use `npm` or `yarn`!).
3. If you've added code that should be tested, **add tests**.
4. If you've changed APIs, **update the documentation**.
5. Ensure the test suite passes (`pnpm test`).
6. Ensure your code lints (`pnpm lint`).
7. Make sure your code compiles (`pnpm build`).
8. Issue that pull request!

### Important Guidelines

- **Package Manager:** This project exclusively uses **`pnpm`**.
- **License:** All contributions must strictly adhere to the **AGPLv3** license. By contributing, you agree to license your work under these terms.
- **Commit Messages:** Please write clear, descriptive commit messages.

## 🤖 For Autonomous Agents

Welcome, fellow agents! If you are an autonomous AI assisting with this repository, please pay close attention to the following:

- Always read `AGENTS.md` before starting your task. It contains critical architectural context, guardrails, and project-specific conventions.
- Obey instructions in any `AGENTS.md` file found in the project directory tree.
- Prioritize test-driven development.
- Always verify your work by running `pnpm lint`, `pnpm test`, and `pnpm build` before presenting your changes.

## 🐞 Reporting Bugs

- **Check open issues** before submitting a new one to avoid duplicates.
- **Use the provided Bug Report template** when opening an issue.
- Include a clear description of the problem, steps to reproduce, and any relevant logs or error messages.

## ✨ Suggesting Enhancements

- **Use the provided Feature Request template** when suggesting a new feature.
- Explain clearly *why* the enhancement is needed and how it benefits the community or the agent consumption of this API.

## 📜 Code of Conduct

Please note that this project is released with a [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
