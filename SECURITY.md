# Security Policy

## Supported Versions

Currently, only the latest version of ipfs-pay-to-pin-client is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately via GitHub's Private Vulnerability Reporting feature for this repository. We will acknowledge your report within 48 hours, and you'll receive a more detailed response within 7 days indicating the next steps in handling your report.

If you have not received a reply to your email or GitHub report within 48 hours, or have not heard from the security team for the past 7 days, there are a few steps you can take:

- Contact the maintainers directly.
- Open a generic issue asking for a security contact (without disclosing the vulnerability details).

Thank you for helping keep ipfs-pay-to-pin-client and our users safe!
