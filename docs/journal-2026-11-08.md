# Journal Entry - 2026-11-08

## Maintenance: Node.js Target Alignment

Today I aligned the `devDependencies` with our explicit Node.js target (`20`).
Previously, `@types/node` was floating at `^22.20.5`, causing a discrepancy
between our local tooling types and the CI/CD, `package.json` engines constraint
(`>=20.0.0`), and `.node-version`.

I have explicitly downgraded `@types/node` to `^20.0.0` in `package.json` and
updated the lockfile. This ensures that type checks run against the correct types
for our lowest-supported target version, thereby increasing reliability and avoiding
future drift.
